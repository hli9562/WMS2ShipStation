# Carrier logo assets

Local copies used only to identify carriers in shipping quotes. Carrier names and
logos belong to their respective owners. Downloaded from official carrier sites:

- USPS: https://www.usps.com/global-elements/images/logo-sb.svg
- UPS: https://www.ups.com/assets/resources/webcontent/images/ups-logo.svg
- FedEx: https://www.fedex.com/content/dam/fedex-com/logos/FedEx-Logo.png
- GlobalPost: https://www.goglobalpost.com/wp-content/uploads/2025/01/globalpostlogo.svg

The client uses a carrier-name fallback for unknown carriers or unavailable images.
No external logo requests are made by the browser.
